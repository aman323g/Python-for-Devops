# ✅ TASK 1: Create GitHub repo & push your folder

### 🔹 Step 1: Create a new repository on GitHub

1. Open 👉 [https://github.com](https://github.com)
2. Click **+ → New repository**
3. Repository name:
   👉 `python-for-devops`
4. Set:

   * Public or Private (your choice)
   * ❌ Do NOT check “Add README”
5. Click **Create repository**

Keep this page open — you’ll get a repo URL like:

```
https://github.com/your-username/python-for-devops.git
```

---

### 🔹 Step 2: Open your project folder in terminal

Open **Command Prompt / PowerShell** and run:

```bash
cd "D:\UDEMY COURSES\Python for Devops"
```

Check:

```bash
dir
```

You should see your project files.

---

### 🔹 Step 3: Initialize git

```bash
git init
```

---

### 🔹 Step 4: Create .gitignore (VERY IMPORTANT for venv)

Inside this folder, create a file named:

👉 `.gitignore`

Open it and add:

```
venv/
__pycache__/
*.pyc
.env
```

Save it.

This prevents your virtual environment from going to GitHub.

---

### 🔹 Step 5: Add files & first commit

```bash
git add .
git commit -m "Initial project setup"
```

---

### 🔹 Step 6: Connect local folder to GitHub repo

Copy your GitHub repo URL and run:

```bash
git branch -M main
git remote add origin https://github.com/your-username/python-for-devops.git
git push -u origin main
```

✅ Done — your folder is now connected to GitHub and pushed.

---

# ✅ TASK 2: Section-wise branch workflow

We will follow this professional flow:

> Section branch → work → commit → push → merge into main

---

## 🔹 When starting a new section (example: section-1)

```bash
git checkout -b section-1-basics
```

Now you are working on section-1 branch.

Check:

```bash
git branch
```

⭐ the active one will have `*`

---

## 🔹 Work normally

Add your Python files, practice code, notes, etc.

---

## 🔹 Save work (commit)

```bash
git add .
git commit -m "Completed Section 1 basics"
git push -u origin section-1-basics
```

---

## 🔹 After section is completed → merge into main

```bash
git checkout main
git pull origin main
git merge section-1-basics
git push origin main
```

Now section-1 is safely in `main`.

---

## 🔹 Start next section

```bash
git checkout -b section-2-oops
```

Repeat same process.

---

# ⚠️ Common mistakes to avoid

❌ Never push `venv`
❌ Don’t work directly on `main`
❌ Always commit section-wise
✅ Small commits
✅ Clear messages
